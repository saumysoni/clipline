Scheduled

Each Short goes public at its time. You can change anything in YouTube Studio before then.

    imageSet each Short's thumbnail in the Shorts feed

    YouTube doesn't let apps set the picture shown in the Shorts feed, so it takes one quick step per Short. Clipline already set the thumbnail used in search, on the home page and in subscriptions.

    1. Any channel, in the YouTube app: open the Short, tap Edit, then the thumbnail, and pick the very first frame. Clipline put the thumbnail there (it's too short for viewers to notice).
    2. Partner Program channels, in YouTube Studio: use Download thumbnail, then Open in Studio and upload the image as the thumbnail.

    If a Short says YouTube didn't take the thumbnail, the channel usually isn't phone-verified yet. That takes a minute at youtube.com/verify.

    infoIf your Google project hasn't passed YouTube's API audit yet, YouTube keeps these uploads private. Open each one in YouTube Studio to set it public or scheduled.
